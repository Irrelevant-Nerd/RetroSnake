# Retro Snake

## A classic Snake Game built with C++ and CMake using SFML 3 library

It features a very simple gameplay where you play as a snake that eats an apple, each one you eat gives you a score. It gets harder and harder as you progress

### Language, Tools and Library used
- C++
- VS Code
- CMake
- SFML 3

### How the game works
- To move the snake:
``` W - UP, S - DOWN, A - LEFT, D - RIGHT ( Using the arrow keys also do the same ) ```

- Press H key to hide the text displayed for more comfortable gameplay, press it again to display the text back

- You start at level 1, the level gets progressively higher as you eat more apple

- Hitting the border or your own body will result to game over

### How to install and play the game!
1. Clone the repository to a path
``` https://github.com/Irrelevant-Nerd/RetroSnake.git ```

2. Download MSYS2 from the official website - https://www.msys2.org/

3. Install the mingw64 compiler from MSYS2

4. Download SFML from official website https://www.sfml-dev.org/

4. Start setting up the compiler and the SFML library, watch this YouTube video - https://youtu.be/RHrU3I1nsEI?si=pfwVPEmX16rw6lim

5. Run the .exe file inside the build directory
``` build/ ```
